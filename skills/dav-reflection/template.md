# 反省報告模板

> 反省報告 v2.0 起**併入交付摘要的「## 反思」末段**（唔再另開獨立檔）。
> 本檔畀出 3 個級別（US / Sprint / Module）嘅骨架。

## 使用說明

1. **選擇模板**：根據反省級別選擇對應的模板
2. **併入交付摘要**：填入交付摘要的「## 反思」末段（v2.0 起唔另開檔）
3. **每個問題要對應 Backlog**：反省中發現的每個問題都要在 `docs/backlog.md` 新增對應的 item
4. **跟用戶確認**：Sprint 和 Module 級別的報告完成後，要跟用戶確認 Action Items
5. **保留歷史**：報告隨交付摘要保留，作為日後追溯的歷史記錄
