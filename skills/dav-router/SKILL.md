# Dav Router

## TL;DR

1. **做什麼**：任務分流（一般任務 vs 開發編程任務）＋ 輕量執行 ＋ 升級判定；兼做 SOP 違規回報（防線）。
2. **何時觸發**：一般任務（唔寫 code）／執行途中發現要寫 code／用戶未指定用邊個 skill。
3. **關鍵紀律**：一次一個問題（V01）；方案必標 ⭐ 推薦（V02）；唔好偷偷寫 code。
4. **必產出物**：完成內容 ＋ 一句講解（一般任務唔使交付摘要、唔使反省、唔寫 backlog）。

## 觸發時機

- **一般任務**（查資料／生成音樂、圖片、PDF、PPT／文件潤稿／單次問答）→ ✅ 必須
- **執行途中發現要寫 code／要建 backlog／範圍要拆** → ✅ 必須（任務升級判定）
- **已經喺執行段（`dav-developer`）／交付段（`dav-reviewer`）／規劃段（`dav-planner`）** → ❌ 唔好重複觸發

## 流程（3 步）

- **Step 1 分流** — 判斷係一般任務定開發編程任務；開發編程任務 → 交返 `dav-planner`（規劃）起步
- **Step 2 輕量執行** — 問清楚（一次一題）→ 用合適嘅 skill／工具做 → 結束時簡單講解完成咗乜
- **Step 3 升級判定** — 出現升級觸發器 → 即刻停低 ＋ 明示「⚠️ 任務升級」＋ 等用戶確認

## 規則 / 例外 / 限制

- **唔寫 code 唔好走全套流程** — 例外：升級觸發器命中；限制：一般任務唔使 backlog／交付摘要／六維度反省
- **升級觸發器命中 → 必須停低講**（4 條觸發器 ＋ trust 例外）→ 同套 `./rules.md` §1
- **違規回報（跳過 gate／假報通過 → 即刻停低講）** → 同套 `./rules.md` §2
- **結束時一定要講解完成咗乜** — 例外：無；限制：唔准淨係交個檔案路徑就算

## 交叉引用（純文字）

- 分流細節、升級觸發器、違規回報 → 同套 `./rules.md`
- 規劃階段規則 → 見同套 `dav-planner` skill；執行段 → 見同套 `dav-developer` skill
