# 需求對帳表 — 可複製範本

> 本檔為 `dav-reconciler` skill 的子檔：**填好就可以直接寫入** `docs/reconcile/<US-ID>-reconcile.md` 嘅對帳表骨架。
> 欄位規則、狀態值判定、完整性規則 → 見同 skill 子檔 `reconcile-format.md`。
>
> ⚠️ 對帳表**必須**用 markdown 表格：文件漂移檢查（D7）靠 `| R<n> |` 列 + 狀態符號（✅／⚠️／❌／🚫）解析對帳表 → 改成列表會令 D7 變「解析不到任何列」。

```markdown
# <US-ID> 需求對帳表

> 對帳者: <subagent 名稱> | 對帳時間: <YYYY-MM-DD> | 錨點: docs/req/<US-ID>-requirement.md
> 覆蓋率: <已列 R-ID 數>/<錨點 R-ID 總數>

## 對帳表

| 需求 ID | 需求句（摘要） | 狀態 | 實作位置 | 證據 | 備註 |
|---------|---------------|------|---------|------|------|
| R1 | <一句話> | ✅ 已實作 | <path>:<line> | <測試名 / 指令> | |
| R2 | <一句話> | ⚠️ 部分實作 | <path>:<line> | — | <缺什麼> |
| R3 | <一句話> | ❌ 未實作 | — | — | <為什麼沒做> |

## 結論

- 全部已實作 / 有 <n> 項部分實作 / 有 <n> 項未實作
- 對帳者備註: <一句話；不得替執行者辯護>
```
