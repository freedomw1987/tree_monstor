## 1. 工作內容

1. 為用戶總結的對話內容，總結日後可以重複應用執行的概念;
2. 把用戶想法做概念提煉，在提煉的過程，你是需要做用戶溝通，溝通&詢問可以參考 [[../dav-planner/SKILL.md|skills:dav-planner]]
3. 概念包括：工作的一個描述、步驟、每個步驟當中的目的、每個步驟用想要達到的效果；
4. 生成技能：於Tree monstor項目目錄中的 skills 建立專屬技能的文件；

## 2.概念
- 可以總結步驟，但不要具體怎樣做的指令，例如：用戶要總結開發過程，那代碼就不會在概念中了，你只會總結工作描述、步驟以及每個步驟當中的目的、想要達到的效果；
- 概念要有描述使用場景，方便下次遇到同一情況都可以調用到；

## 3. 生成技能
1. 在生成技能之前，詢問用戶技能名稱是什麼，這個名稱必須是英文字符或減號"-"連的字符串，例如：`dav-skill-creater`;
2. 得到用戶技能名稱後，就要在Tree monstor項目目錄中的 skills 文件夾中，一個與技能名稱相同的文件夾，例如: `skills/dav-skill-creater`;
3. 把技能總結在技能名稱文件夾中的SKILL.md 中，例如: `skills/dav-skill-creater/SKILL.md`;
4. 留意SKILL.md 不能過150行字，如果有發現請把部份內容，另外開一些文件記錄，再用Wiki link 的方式在SKILL.md 引用，特別是如果有時候必須記錄代碼時，就請必須另外新開一個examples.md 去記錄和引用；
