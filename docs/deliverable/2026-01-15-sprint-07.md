## 1. 完成什麼

### TD-005：AC-11a 改為更精準冪等測試

`tests/install.bats` 的 AC-11a 從「hash-based 全檔案 find」改為「具體 install 管理檔案清單 + sha256」：

```bash
snapshot_install_state() {
  # 列出 $home/.claude / .pi / .agents/tree_monstor 的檔案
  # 對每個：realpath + type + sha256 (file) 或 target (symlink)
  # 整個清單 sort 後 sha256
}
# 跑兩次 install，比對 snapshot hash
```

**為什麼更精準**：
- 不依賴 `find` 排序（macOS / Linux 排序不一致）
- 不依賴 mtime / permissions（容器 / CI 可能不同）
- 只比對 install 管理的子樹（不汙染 $HOME 其他檔案）

### TD-008：install.sh Magic strings 集中

在 Defaults 區塊新增 6 個 `readonly` 常數：

```bash
readonly DIR_CLAUDE=".claude"
readonly DIR_PI=".pi"
readonly DIR_AGENTS=".agents"
readonly LOADER_MARKER="tree-monstor-loader:DO-NOT-EDIT-START"
readonly LOADER_END_MARKER="tree-monstor-loader:DO-NOT-EDIT-END"
readonly KNOWN_AGENTS=("claude" "pi")
```

**重構覆蓋**：
- 7 處 `local xxx="$TARGET_ROOT/.claude"` → 全部用 `$TARGET_ROOT/${DIR_CLAUDE}`
- 11 處 log_plan 顯示字串保留（給用戶看的 plan，不影響邏輯）
