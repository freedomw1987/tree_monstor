## 是否需要 API key？

**完全不需要**。Sprint 08 全部 self-contained：

| 工具 | 是否需 API |
| --- | --- |
| `wiki-extract-media.sh` | ❌ 不需要 |
| `wiki-extract-video.sh` | ❌ 不需要 |
| `wiki-extract-audio.sh` | ❌ 不需要 |
| `wiki-merge-media.sh` | ❌ 不需要 |
| `wiki-media-describe.sh` | ⚠️ **可選**：預設 mock，真實 API 是進階功能 |

`wiki-media-describe.sh` 設計以 `DAV_WIKI_MOCK=1` 為預設，可選以下進階模式：
- 不設環境變數 + 不傳 `--api-key` → mock 模式跑完整 pipeline
- 提供 `OPENAI_API_KEY` 或 `--api-key` → 走真實 Vision / Whisper API
