## 格式（trust mode 新增未決項時照此追加）

每個未決項一個 `## NYH-<n>` 段落，內含下列欄位（缺一即為不合格條目）：

| 欄位 | 內容 |
|------|------|
| 事件 | 發生什麼（事實描述，不加推測）|
| 影響 | 影響範圍與曝露面 |
| 最推薦 | **第一個選項必須是最推薦**，並寫明原因 |
| 替代 | 其餘選項，各附結果與效果 |
| 保守默認 | trust 期間照此辦理（通常是「不修改任何檔案」）|
| 抉擇欄 | `- [ ] ✅ 繼續做（YYYY-MM-DD ask-me）` → 用戶回答後由 `ask-me` 改為 `- [x] ✅` 並補寫理由 |
| backlog 對照 | `TMO-xxx`（狀態須**同步**寫進 `docs/backlog.md`——雙寫缺一即視為未完成）|
