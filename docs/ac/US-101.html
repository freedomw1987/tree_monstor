背景

本 AC 對應 US-101「信用卡快速結帳」。作為顧客，我想使用信用卡快速結帳，以便迅速完成購買。

Given / When / Then

Given 用戶已登入且購物車有商品
When 用戶點「結帳」按鈕
Then 系統在 3 秒內導向付款頁
And 付款頁支援 Visa / MasterCard
Given 用戶在付款頁輸入卡號
When 輸入的卡號格式錯誤（如少一位數）
Then 系統在 1 秒內顯示紅字錯誤訊息「卡號格式錯誤，請重新輸入」
Given 用戶完成付款且交易成功
When 系統收到金流回傳 success
Then 系統在 3 秒內發送 Email 通知給用戶（含訂單編號、金額、預計出貨日）
Given 用戶完成付款且交易失敗（金流回傳 error）
When 系統偵測到付款失敗
Then 系統顯示明確的錯誤訊息（不可為空白）
And 購物車內商品不消失（用戶可重試）
