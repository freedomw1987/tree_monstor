# TMO-085 測試體系減法 ＋ 探針 skill-local 化 ＋ 唔記歷史

> 對應 Backlog: TMO-085
> 最後更新: 2026-10-27
> 狀態: done (2026-10-27)

## 背景

用戶 2026-10-27 一連提出 5 條決策（見 `docs/req/TMO-085-requirement.md`）：
① 測試只保留真 python／shell 功能測試；② 文檔行數限制寫入 `dav-skill-creater` 規範；
③ 所有 CHANGELOG 一律唔要；④ skill 唔記歷史變動；⑤ skill 相關探針搬入 `skills/<name>/tests/`，
   改個別 skill 就淨跑嗰個 skill。

## Given / When / Then

### AC01

- **Given** repo 內 47 支探針（刪減前）
  **When** 按「對象係可執行碼 vs 文件內容」分類
  **Then** 對象係**文件／規格內容**嘅探針全部刪走（agents-md／doc-facts／framework-weight／
  skill-size-guard／markdownlint-guard／gate-in-skill／probe-name-ascii／restruct-*／
  docs-reduction／v2-reduce-deliverables／backlog-trust-mode／dav-planner-* 等），
  對象係 **python／shell 碼**嘅保留（wiki／pptx-slim／install／poc／env-equivalence／
  mutant-must-die／secret-masking／local-ci-guard／doc-drift 等）
  ——連帶清埋死碼工具、mutant 列、CI／本機閘步驟（**唔留死引用**）

### AC02

- **Given** 原本用機械探針守「文檔行數」
  **When** 睇 `skills/dav-skill-creater/editor-guide.md`
  **Then** 有「文檔行數限制（v2.8）」章（主檔 ≤150／子檔 ≤300／context ≤700；超標先減法再拆檔）
  ＋ `SKILL.md` 規則行；而 `check-framework-weight.py`／`check-skill-size.sh` 及其探針已刪

### AC03

- **Given** 13 個 skill ＋ `docs/sop/handbook/changelog.md`
  **When** 搵任何 `CHANGELOG.md` 引用
  **Then** 全部檔案已刪、全部引用已清（`SKILL.md` 指標、探針斷言、交叉引用）

### AC04

- **Given** 每個 `skills/*/SKILL.md`
  **When** 睇有冇 `## 變動歷史` 段
  **Then** 全部冇；而 `dav-skill-creater` 嘅「任務導航」已由 5 段改 4 段、規範章節已改寫

### AC05

- **Given** skill 相關嘅探針（wiki／pptx-slim／poc／doc-drift）
  **When** 改一個 skill
  **Then** `bash scripts/test-skill.sh <skill>` 淨跑嗰個 skill 嘅測試（唔使等成 repo 套件）；
  CI 同時跑 repo 級 `tests/` ＋ skill 級 `skills/*/tests/`（兩條路徑都有人跑，冇 orphan 探針）

## 風險

- **減法之後，文件類規則冇機械守門** → 改由 `dav-skill-creater` 規範（agent 自律）承擔；
  代價已明文記錄（CONTRIBUTING「文檔行數限制」段）
- **刪探針＝放寬閘** → 依 V03 走獨立二審，並喺交付摘要逐項列出刪咗乜、剩低乜
- **探針搬位會令路徑失效** → 搬完要逐支跑過（`bats tests/` ＋ `bats skills/*/tests/`），
  且 `REPO_ROOT` 一律用 `BATS_TEST_DIRNAME/../../..` 反推（唔靠 `git rev-parse`）
