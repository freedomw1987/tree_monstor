# TMO-054 OpenRouter API key 輪替（人工項）

> 對應 Backlog: TMO-054
> 最後更新: 2026-10-28
> 狀態: blocked (2026-10-05 接受風險；⏸️ 跳過 —— 只有用戶可執行)

## Given / When / Then

### AC01

- **Given** 本機 OpenRouter key 曾經被印入 session log（2026-10-05 NYH-1）
  **When** 用戶喺 OpenRouter 撤銷舊 key、產生新 key，並更新本機 key 來源（PoC `.env` 檔，gitignore 內；或 `~/.zshrc` 環境變數）
  **Then** 舊 key 失效、新 key 生效；由 Agent 複驗 sha256 已變 ＋ 新值未出現在任何被追蹤檔／本輪 diff

### AC02

- **Given** 用戶已決定「接受風險、不輪替、保留現狀」（2026-10-05 結案決策）
  **When** 本票以 ⏸️ 跳過結案
  **Then** 舊 key 續用（`.env` 與 `~/.zshrc` 兩處並存），洩漏風險由用戶承擔，本票不再處理

## DoD（Definition of Done）

- [ ] 用戶完成 key 輪替（AC01），或明確維持現狀（AC02；2026-10-05 已結案）
- [ ] 輪替後由 Agent 複驗 sha256 已變 ＋ 新值未出現在任何被追蹤檔／本輪 diff
- [ ] 本票完成後由 `docs/backlog.md` 移出（規則見 `skills/dav-planner/backlog-rules.md` §4.5）

## 風險

- **Agent 無法代為撤銷**（要用戶登入 OpenRouter 帳號）→ 本票只可由用戶執行，Agent 最多做複驗
- **新 key 唔可以貼入對話／session log**（會再洩漏一次）→ 只喺本機終端操作
- **接受風險＝長期承擔未知洩漏面**（2026-10-05 抉擇理由：session log 可能被同步／保存）
