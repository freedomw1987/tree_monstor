# TMO-084 CI 降級為「偵測器」＋ 落地本機等價閘

> 對應 Backlog: TMO-084
> 最後更新: 2026-10-27
> 狀態: done (2026-10-27)

## 背景

本 repo 係**平時自用嘅技能庫**，唔係要出貨嘅產品 → 用 GitHub Actions 做「完成條件」係過度。
但 CI 有一個本機**結構上做唔到**嘅價值：佢係**另一部機**（clean clone、雙 OS、乾淨依賴、冇 API key、冇暖快取）。

決策（2026-10-27 用戶）：**CI 降級為「偵測器」，閘改為本機**。

## Given / When / Then

### AC01

- **Given** `.github/workflows/ci.yml` 嘅檢查步驟
  **When** 跑 `bash scripts/check-all.sh`
  **Then** 一條指令跑齊本機閘（原本 13 步；2026-10-27 減法後 11 步，由便宜到昂貴、fail-fast）。**步驟名**同 ci.yml 雙向對齊；
  markdownlint glob／doc-drift `--from-date` **執行時由 ci.yml 抽**（唔硬編 → 唔會漂移）。
  ⚠️ **已知邊界**：對齊只及於「step 名 ＋ 該兩個參數」，**唔及於 step body**——
  ci.yml 若改某步嘅指令內容（例如 `bats tests/` → `bats -j 4 tests/`），本機 runner 唔會自動跟。

### AC02

- **Given** 本機閘嘅任何一步失敗
  **When** 跑 `scripts/check-all.sh`
  **Then** 整體非 0 退出；全檔**冇** `|| true` / `set +e` 類 fail-open
  （⚠️ 行為自證以 `deps` 步為代表：LC-8 用 `LOCAL_CI_SELF_TEST_FAIL=deps` 觸發；
  其餘步驟共用同一條失敗匯總路徑）

### AC03

- **Given** ci.yml 同本機 runner 嘅步驟集
  **When** 跑 `tests/local-ci-guard.bats`
  **Then** **雙向**對齊：CI 有嘅本機冇 → 紅；本機有嘅 CI 冇 → 紅；並有 mutant 證明「有步驟失敗時整體一定紅」

### AC04

- **Given** 閘嘅放寬（CI 由閘變偵測器）
  **When** 交付
  **Then** 已經獨立 Reviewer subagent 二審（V03），結論隨交付摘要呈現；並**誠實記錄代價**（跨 OS／跨版本差異而家只係通知）

### AC05

- **Given** 開發者想 push 前自查
  **When** `bash scripts/install-local-hooks.sh` 然後 push
  **Then** pre-push 自動跑本機閘；紅就擋 push；`SKIP_LOCAL_CI=1 git push` 可一次性繞過（會印警告）；安裝器**唔會靜靜哋覆蓋**原有 hook（先備份）

### AC06

- **Given** 2026-10-27 用戶決策「regression-guard 的 ci 在本地跑都得，不用在 github 上跑」
  **When** 行 `bash skills/regression-guard/PoC/run_ci.sh <subcommand>`
  **Then** 一條本機指令承擔原本 workflow 嘅 4 個 job（`probes`／`pipeline`／`matrix`／`cleanup-scan`）；
  **return code gate 語義不變**（綠 0／黃 2／紅 1，另有 3 = 用法／環境錯誤）；
  原 workflow **已刪除**（探針 `CI-f` 鎖住唔准加返）；目標專案用 GitHub Actions 嘅教學保留喺 SOP。
  ⚠️ **已知邊界**：cleanup-scan 冇自動每週跑（原本係 workflow 嘅 cron job）→ 要自己排程或人手跑；
  verdict 由 batch report JSON 讀（`run_pipeline.sh` 嘅離開碼永遠係 0 → 原本 workflow 其實捉唔到紅燈）。

## 風險

- **CI 紅唔再阻 merge** → 跨 OS／跨版本嘅真 bug 可能漏網 → 靠本機閘守住自己嗰邊（乾淨 clone 嘅坑要用 `git add -A` 先跑閘）
- **本機閘唔等於 CI**（結構上做唔到跨環境）→ 文件必須明寫，唔准令人誤以為「本機綠 = CI 綠」
- **本機閘好慢**（mutant 全表為主，全程 ≈ 10–15 分鐘）→ 步驟由便宜到昂貴排序、fail-fast；可用 `--only <id>` 跑單步
- **閘本身可能被改到假綠** → mutant `LC-M1` ＋ LC 守門探針雙重保護
