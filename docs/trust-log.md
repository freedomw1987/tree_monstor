## 格式（trust mode 進行中追加）

| # | 時間 | 階段 | 問題 / 決策 | 理由 | 可推翻 |
|---|------|------|-----------|------|--------|

- **時間**：標 `*` = `git log` 實錄 commit 時間；標 `~` = 由相鄰 commit 推估（誠實揭露，不用假精度）。
