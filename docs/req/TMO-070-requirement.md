# TMO-070 需求錨點

> US: TMO-070 | 建立: 2026-10-26 | 來源: 2026-10-26 §2.1 規劃訪談（用戶對話）

## 用戶原話（唯讀）

- R1: 「我發現有一個問題，就是用戶提出需求，到最後ai 出來的成果對不上」
- R2: 「獨立 subagent + 硬門檻（推薦）」

## 澄清後驗收句

- R1: 成果與需求的落差必須由**獨立第三方**判定，不能由執行任務的同一個 Agent 自評自證
- R2: 對帳由未參與實作的獨立 subagent 執行；對帳結果有「未實作 / 偏離」時**不得**宣告
  「✅ 完成」，只能標「⚠️ 部分完成」並列出待補項
