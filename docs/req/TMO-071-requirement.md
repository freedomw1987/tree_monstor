# TMO-071 需求錨點

> US: TMO-071 | 建立: 2026-10-26 | 來源: 2026-10-26 §2.1 規劃訪談（用戶對話）

## 用戶原話（唯讀）

- R1: 「其中一個問題是流程中過了幾部分文件，所以文件翻譯上出落差」
- R2: 「5 類字面對帳（推薦）」

## 澄清後驗收句

- R1: 同一件事在多份文件間的**字面不一致**必須能被機械化抓出，不靠 AI 自省
- R2: 探針涵蓋 8 類字面對帳 D1..D8（AC 狀態同步 / AC 編號連續唯一 / 追溯矩陣無幽靈 ID /
  交付摘要檔案存在 / md 與 html 狀態一致 / AC 範本 ↔ 需求錨點對應 / 對帳表 R-ID 覆蓋 /
  交付摘要對帳段與狀態一致）；存量已知不一致以**帶理由的白名單**豁免，不得誤紅
